# REIANNA

Premium minimal luxury fine-jewellery website prototype for India.

Positioning: **Jewellery, Made Personal.**

This is a static GitHub Pages-ready site. It includes:

- Editorial homepage
- Curated collection cards
- Product detail drawer
- Custom Studio inquiry flow
- Wishlist, inquiry cart, search, profile, and WhatsApp actions
- Responsive mobile bottom navigation

## Local Preview

Open `index.html` directly, or serve the folder with any static server.
